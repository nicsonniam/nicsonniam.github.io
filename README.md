# 🌐 Personal Portfolio (Astro)

A modern personal portfolio built with **Astro**, **Tailwind CSS**, and deployed via **GitHub Pages**.

Showcasing projects, experience, and skills as a full-stack web developer.

---

## 🚀 Tech Stack

- Astro (Static Site Generator)
- Tailwind CSS
- TypeScript
- GitHub Actions (CI/CD)
- GitHub Pages (Deployment)

---
